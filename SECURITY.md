# Security policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use
GitHub's private vulnerability reporting feature or contact a repository owner
privately with:

- the affected endpoint or component;
- reproduction steps or a minimal proof of concept;
- the likely impact; and
- any suggested mitigation.

Do not access, modify, or retain data that does not belong to you while testing.
The maintainers should acknowledge a complete report within seven days and
coordinate disclosure after a fix is available.

## Supported versions

Until the first stable release, security fixes are applied to the latest commit
on `main`. Experimental branches are not deployed releases.
